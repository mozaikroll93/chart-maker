# CP 关系图生成器

做 shipping chart（CP 关系图）的网页小工具：角色头像自动排成一圈，图例点一下就能改，连线有手画的感觉，最后导出 PNG。

- **加角色**：拖图片进来、Ctrl/⌘+V 粘贴、点「添加图片」，或者从 [Bangumi](https://bgm.tv) 搜作品一键导入角色。
- **图例**：画布上点文字直接改（「锁死」「OTP」「可以吃」都行），点色块换颜色，可以增删。
- **连线**（按 L 或点「连线」）：从一个头像拖到另一个，或者先点一个再点另一个。线的颜色就是图例的颜色，改图例颜色时线会跟着变。
  - 选中线后拖中间的圆点调弧度；双击线可以写字，字会沿着线走。
  - 支持箭头（单向/双向）、一条线分段多色、调粗细。
  - 三种笔触：笔刷（默认）、铅笔（反复描线）、干净。
- **其他**：标题和作品 logo、画布上随手写字（按 T）、撤销/重做、自动保存到浏览器、工程文件导入导出。
- 头像拖离圆环就能自由摆放；「把所有角色放回圆环」一键恢复。

单圈最多 60 个角色；超过 36 个会提示手机上看可能偏小。依据见 [docs/capacity.md](docs/capacity.md)。

## 运行

纯静态网页，没有依赖，也不需要构建：

```sh
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

部署时把整个仓库放到任意静态托管上即可（GitHub Pages：Settings → Pages → Deploy from branch，选这个分支的根目录）。

## 结构

| 文件 | 内容 |
|---|---|
| `js/state.js` | 文档数据、画布预设、圆环布局、撤销栈 |
| `js/render.js` | 把文档画成 SVG（头像、连线、图例、标题） |
| `js/stroke.js` | 手绘线条：两端收笔、粗细起伏、低频抖动 |
| `js/interact.js` | 画布上的拖动、连线、就地编辑文字 |
| `js/panels.js` | 左侧角色列表、右侧属性面板、工具栏 |
| `js/bangumi.js` | Bangumi API 搜索作品、导入角色 |
| `js/exporter.js` | 导出 PNG（内嵌手写字体）、工程文件 |
| `js/images.js` | 图片压缩，加载跨域图片 |

## 隐私

所有内容都只存在浏览器里（IndexedDB），不会上传。只有用 Bangumi 导入时，浏览器才会直接访问 `api.bgm.tv`；如果 Bangumi 的图床不允许跨域，会改用公共图片代理 `wsrv.nl` 下载头像。
